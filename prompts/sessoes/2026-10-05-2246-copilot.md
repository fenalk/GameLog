## Usuário

Como posso fazer para que o docker funcione?

## Copilot

Diagnostiquei duas causas (nenhum arquivo alterado):

1. **Permissão no socket** — o daemon está ativo e habilitado e o socket é `root:docker` modo
   `660`, mas o usuário `fernanda` não pertencia ao grupo `docker` (`id -nG` não listava
   `docker`), daí o *permission denied*.
2. **Plugin Compose ausente** — o pacote `docker.io` do Ubuntu (29.1.3) não traz o subcomando
   `docker compose`; `/usr/libexec/docker/cli-plugins/` só tinha `docker-trust`. O pacote
   `docker-compose-v2` (2.40.3) estava disponível no repositório apt.

Passei as instruções (exigem sudo, que eu não tenho de forma não interativa):

```bash
sudo usermod -aG docker "$USER"        # entra no grupo docker
sudo apt install -y docker-compose-v2  # instala o plugin `docker compose`
# opcional: sudo apt install -y docker-buildx
```

Com notas sobre: logout/login (ou `newgrp docker`) para o grupo valer; reiniciar o VS Code para
o processo herdá-lo; verificação com `docker run --rm hello-world` e `docker compose version`;
fluxo do projeto (`docker compose up -d db` + `npm run db:deploy` com Node 24); e o alerta de
que o grupo `docker` equivale a privilégio de root.

> Escolha do usuário: **só queria as instruções**
